# Coal-Mine-Production-Analysis
From Coal Production Data to Management Insights

As part of my continued journey in Data Analytics and Business Intelligence, I developed this interactive Coal Mine Production Performance Dashboard using a synthetic dataset created for learning and portfolio purposes.

The objective was not simply to build charts.

I wanted to simulate a real business question:

“If a mine is producing below target, how can data help management understand what is driving the shortfall and where attention should be focused?”

Using production, equipment availability, utilisation and downtime data, I structured the analysis around the management decision-making process:

Production → Target Achievement → Equipment Performance → Downtime → Risk → Possible Causes → Management Action

📊 What does the dashboard tell us?

The operation produced 8.18M tonnes against a target of 8.27M tonnes, achieving approximately 99% of target, but still ending the period around 84.4K tonnes below plan after accounting for periods of production surplus.

The more interesting insight comes from equipment performance.

Average equipment availability was approximately 88.2%, while utilisation averaged only 78.0%. This suggests that having equipment available does not necessarily mean that the available capacity is being fully converted into production.

The dashboard therefore helps shift the management question from:

“Is our equipment available?”

to:

“If the equipment is available, what is preventing us from using it effectively?”

The analysis also highlights October as the weakest production month, identifies differences in achievement across the three pits, and classifies production days according to operational risk and potential causes of shortfall.

💡 My biggest learning from this project:

A good dashboard should do more than report KPIs.

It should help users move from:

What happened? → Where did it happen? → Why might it have happened? → What should we investigate next?

I also incorporated dynamic management commentary so that the dashboard translates the selected data into concise operational insights rather than expecting decision-makers to interpret every visual themselves.

This project helped me strengthen my skills in:

• Data analysis and KPI development
• Production vs target analysis
• Equipment availability and utilisation analysis
• Root-cause-oriented analytics
• Interactive dashboard design
• Translating operational data into management insights
• Data storytelling and decision support

The next step in my learning journey is to take this further by integrating predictive analytics, so that instead of only identifying production risks after they occur, the analysis can help anticipate potential production shortfalls before they happen.

Note: All data presented in this dashboard is synthetic and was developed solely for learning, demonstration and portfolio purposes.
